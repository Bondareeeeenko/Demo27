# Отчёт по проверке стиля и качества кода

Дата проверки: 23.11.2026

## 1. Использованные инструменты

- flake8 — проверка соответствия стилю Python.
- pylint — статический анализ кода.
- pytest — запуск автоматических тестов.

## 2. Результаты pylint

Итоговая оценка: 8.82/10.

Обнаружены следующие замечания:

- Повторяющиеся фрагменты кода в разных модулях.
- Дублирование логики расчёта стоимости материалов и операций.
- Похожие блоки обработки запросов в представлениях и маршрутах.
- Повторяющиеся проверки прав администратора.

## 3. Результаты flake8

Обнаружены следующие проблемы:

- E501 — строки превышают рекомендуемую длину.
- W293 — пробелы на пустых строках.
- W291 — пробелы в конце строк.
- E303 — избыточное количество пустых строк.
- F401 — неиспользуемые импорты.

Замечания встречаются в нескольких модулях приложения: blueprints, services, views, config и других.

## 4. Результаты pytest

Всего обнаружено и выполнено 14 автоматических тестов.

Результат: 14 passed.

Проверены:
- Авторизация пользователя.
- Обработка неправильного пароля.
- Обработка отсутствующего пользователя.
- Блокировка после нескольких неудачных попыток входа.
- Проверка обязательных полей.
- Доступ к данным текущего пользователя.
- Получение списка заметок.
- Проверка формата ответа.
- Обработка неправильных параметров пагинации.
- Получение отдельной заметки.
- Обработка отсутствующей заметки.

## 5. Выявленные недостатки тестирования

Не обнаружены тесты для некоторых важных сценариев:

- Регистрация пользователя.
- Проверка невозможности самостоятельного назначения роли администратора.
- Выход из учётной записи.
- Проверка доступа к чужим заметкам.
- Создание и удаление заметок.
- Граничные значения пагинации.

## 6. Вывод

Основные функции, покрытые существующими автоматическими тестами, работают успешно.

Статический анализ выявил проблемы оформления кода, неиспользуемые импорты и дублирование отдельных участков логики.

Рекомендуется постепенно устранять дублирование, привести форматирование к единому стилю и расширить набор автоматических тестов.

Исходный код в рамках данной проверки не изменялся.
