# Карта структуры проекта Demo27

**Дата составления:** 23.11.2026

## 1. Общая информация

Проект Demo27 представляет собой веб-приложение на Python с использованием Flask и PostgreSQL.

Точка запуска приложения — файл `run.py`.

## 2. Структура проекта

### app/
Основная папка приложения, содержащая программную логику.

- `blueprints/` — маршруты и обработчики запросов Flask.
- `services/` — сервисный слой, содержащий бизнес-логику.
- `repositories/` — слой взаимодействия с базой данных.
- `dtos/` — объекты передачи данных.
- `views/` — представления приложения.
- `models.py` — модели данных.
- `auth.py` — функции авторизации.
- `config.py` — настройки приложения.
- `extensions.py` — расширения Flask.
- `utils.py` — вспомогательные функции.
- `puzzle_captcha.py` — логика CAPTCHA.

### database/
Содержит SQL-файлы для работы с базой данных.

- `schema.sql` — структура базы данных.
- `order_cost_query.sql` — SQL-запрос для расчёта стоимости заказа.

### tests/
Содержит автоматические тесты.

- `conftest.py` — настройки и фикстуры тестирования.
- `test_auth.py` — тесты авторизации.
- `test_notes.py` — тесты работы с заметками.

### web/
Содержит HTML-страницы и стили пользовательского интерфейса.

### image/
Содержит изображения проекта.

## 3. Файлы в корне проекта

- `run.py` — запуск приложения.
- `requirements.txt` — список зависимостей Python.
- `.gitignore` — список файлов и папок, исключённых из Git.
- `.env` — локальные настройки и секретные параметры приложения.
